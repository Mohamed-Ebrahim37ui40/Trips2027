جدول الرحلات والحضور - تطبيق ويب يعمل بدون إنترنت

الملفات: index.html, manifest.webmanifest, sw.js, مجلد icons
التثبيت يحتاج رفع الملفات (كلها معاً) على استضافة https مجانية مثل:
Netlify Drop (app.netlify.com/drop) أو GitHub Pages أو Cloudflare Pages.
افتح الرابط مرة واحدة بالإنترنت ثم ثبّته:
- ويندوز/لينكس/ماك (Chrome أو Edge): زر "تثبيت التطبيق" داخل التطبيق أو أيقونة التثبيت بشريط العنوان.
- ماك Safari: ملف > إضافة إلى Dock.
- آيفون: مشاركة > إضافة إلى الشاشة الرئيسية.
- أندرويد: القائمة > تثبيت التطبيق.
بعدها يعمل بدون إنترنت وتظهر أيقونته على سطح المكتب/الشاشة الرئيسية.
البيانات المعدّلة تُحفظ على نفس الجهاز؛ استخدم "تصدير نسخة" للنسخ الاحتياطي.

تشغيل بدون استضافة (على الكمبيوتر): فك الضغط عن الملف أولاً، ثم شغّل start-windows.bat (ويندوز) أو start-mac-linux.sh (ماك/لينكس). يحتاج برنامج Python مثبتاً. سيفتح المتصفح على localhost ومنه تضغط "تثبيت التطبيق". بعد التثبيت يعمل حتى لو أغلقت البرنامج.
ملاحظة: لا يمكن تثبيته من داخل الملف المضغوط ولا بفتح index.html مباشرة من المجلد.
لمعرفة سبب عدم ظهور التثبيت: داخل التطبيق تبويب "ترحيل" ثم "فحص التثبيت".
